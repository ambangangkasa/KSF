# KSF (K-ScanFolder)

*Developed By Khai (IT DEPARTMENT AASB)*

Penerima **Scan to Network Folder (SMB)** untuk MFP Sharp, untuk Windows 7 SP1 hingga Windows 11.

- Daftar destinasi di address book MFP secara automatik (termasuk MFP dengan User Authentication)
- Kemas kini destinasi masa nyata bila IP PC berubah atau entri diubah di MFP
- Akaun & shared folder Windows dibaiki sendiri oleh service latar belakang
- Notifikasi scan baru, beberapa printer, nama scan boleh ditukar

## Muat turun

**[Versi terkini → Releases](../../releases/latest)** — muat turun `KSF-<versi>-setup.exe` dan jalankan.
Kemas kini: jalankan setup baru terus atas versi lama (tidak perlu uninstall).
